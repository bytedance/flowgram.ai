# listenRefValueChange

监听引用变量的值变化并获取完整的变量对象信息。

## API 介绍

### listenRefValueChange

```typescript
listenRefValueChange(
  cb: (props: EffectFuncProps<IFlowRefValue> & { variable?: BaseVariableField }) => void
): EffectOptions[]
```

#### 参数

| 参数 | 类型 | 描述 |
|------|------|------|
| `cb` | `(props: EffectFuncProps<IFlowRefValue> & { variable?: BaseVariableField }) => void` | 回调函数，当引用的值发生变化时触发 |

#### 回调函数参数

| 参数 | 类型 | 描述 |
|------|------|------|
| `name` | `string` | 字段名称 |
| `value` | `IFlowRefValue` | 引用值对象 |
| `form` | `IForm` | 表单实例 |
| `variable` | `BaseVariableField` | 完整的变量对象，包含名称、类型、值等信息 |

### 工作原理

1. **监听值变化**：监听 `DataEvent.onValueInitOrChange` 事件
2. **类型检查**：检查值是否为 `ref` 类型
3. **路径跟踪**：使用 `trackByKeyPath` 跟踪引用路径
4. **变量获取**：获取路径对应的完整变量对象
5. **回调触发**：当变量的值发生变化时触发回调

### 支持值类型

- `IFlowRefValue`：引用类型值，包含 `type: 'ref'` 和 `content: string[]`

### 使用示例

```typescript
const formMeta = {
  effect: {
    'inputsValues.*': listenRefValueChange(({ name, variable, form }) => {
      // variable 包含完整的变量信息
      console.log('变量名称:', variable?.name);
      console.log('变量类型:', variable?.type);
      console.log('变量值:', variable?.value);

      // 将变量信息同步到其他字段
      form.setValueIn(`${name}.variableInfo`, {
        name: variable?.name,
        type: variable?.type,
        value: variable?.value
      });
    })
  }
};
```

### 核心实现

```typescript
export const listenRefValueChange = (
  cb: (props: EffectFuncProps<IFlowRefValue> & { variable?: BaseVariableField }) => void
): EffectOptions[] => [
  {
    event: DataEvent.onValueInitOrChange,
    effect: ((params) => {
      const { context, value } = params;

      // 检查值类型是否为 ref
      if (value?.type !== 'ref') {
        return () => null;
      }

      // 跟踪引用路径的变化
      const disposable = getNodeScope(context.node).available.trackByKeyPath(
        value?.content || [],
        (v) => {
          // 触发回调，传入完整的变量对象
          cb({ ...params, variable: v });
        }
      );

      return () => {
        disposable.dispose();
      };
    }) as Effect,
  },
];
```

### 核心 API

#### `getNodeScope(context.node).available.trackByKeyPath`

跟踪指定路径的值变化，当路径对应的值发生变化时触发回调，返回对应的变量对象。

### 使用场景

- **变量值监控**：实时监控变量的值变化并作出响应
- **数据同步**：将变量的完整信息同步到其他表单字段
- **动态 UI 更新**：根据变量的值动态更新界面显示
- **调试和日志**：记录变量值的变化历史

### 与 listenRefSchemaChange 的区别

- `listenRefValueChange`：获取完整的变量对象，包含名称、类型、值等所有信息
- `listenRefSchemaChange`：直接获取变量的 JSON Schema，用于类型验证和表单生成
