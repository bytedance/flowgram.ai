# FlowGram 工作流节点配置设计

状态：设计草案。本文定义完整目标配置，不代表当前运行时已经支持。范围覆盖 87 个节点入口及其操作，所有节点采用同一套参数、类型、执行和结果展示规则。

已实现的扩展原子节点：对象与结构化数据 9 个、列表 12 个、文本 3 个、数值/日期/编码/哈希 4 个、文档分块 1 个。实际参数、选项和输出以 [公共节点契约](../server/catalog/atomic-nodes.json) 为准，由 Rust 执行并用于生成配置面板及 MCP 发现信息。本文其余条目仍表示目标能力。路径、规则行与条件组均复用共享编辑器；当前文件型、资源型选项在相应能力实现前不展示。

配置面板面向使用者，执行定义面向独立 Rust 后端。手动配置、内置 Agent 和外部 MCP 客户端提交的节点定义，经过相同的校验、资源授权和执行入口。本文不设分批交付目录。面板布局与组件组织以 [节点面板与组件设计](node-panel-ui-and-components.md) 为准。

## 配置面板

节点配置在工作区右侧打开，遵循 [桌面设计规范](desktop-design-system.md)。面板宽度在现有可调整范围内保持稳定；复杂表格、Schema、提示词和代码可展开到工作区编辑页，返回后恢复节点、画布视口和输入位置。

面板结构固定如下，节点只提供各区域中的字段：

| 区域 | 展示与交互 |
| --- | --- |
| 标题 | 类型图标、可编辑名称、类型说明；名称只影响展示，引用使用稳定 ID |
| 配置 | 先显示必填字段和当前操作的常用字段；输入、资源、操作参数按任务顺序排列 |
| 输出 | 显示字段名称、类型、说明、可空性；可展开示例，支持复制字段引用 |
| 运行设置 | 配置页末尾默认收起，集中配置超时、重试、错误行为；显示当前有效的继承值 |
| 测试与结果 | 填写测试输入、执行单节点、查看输入解析值与输出；有明确的测试时间和配置版本 |

一级页签为配置、输出、测试。未填写必填字段时，运行按钮提供可定位的原因。普通字段用即时草稿自动保存；JSON、表达式和代码编辑器允许保留尚未完成的本地输入，解析成功后再提交合法配置。保存失败保留输入并显示重试入口。

每个字段有标签、类型、必填标记、简短说明和错误位置。高级选项按需展开，选择一种操作后只显示相关字段。隐藏字段保留草稿，当前操作的执行快照只包含有效字段。切换资源或操作导致字段类型变化时，展示受影响的映射，不静默删除用户输入。

配置变更不重新挂载画布或面板。条件字段在原位置展开，避免整表入场动画；拖拽面板宽度不使用补间。校验错误采用文字和小面积错误标记，等待、保存、工具执行使用中性色。

### 参数取值

| 方式 | 可用字段 | 交互和执行规则 |
| --- | --- | --- |
| 固定值 | 所有普通数据输入 | 按类型提供文本、数字、开关、对象或列表编辑器，保留空字符串、0、false、null 的区别 |
| 变量引用 | 声明可绑定的数据输入 | 选择可访问作用域中的字段，显示来源、类型和最近测试样本；引用保留原始类型 |
| 文本模板 | 文本字段 | 文本中插入变量标签；对象和数组必须显式格式化，避免隐式变成字符串 |
| 表达式 | 声明可计算的数据输入 | 纯函数表达式，提供类型提示和样本预览；不包含网络、文件、随机数或系统命令等副作用 |
| 资源引用 | 模型、凭证、数据库、MCP、存储、执行器 | 专用选择器；绑定资源 ID 和版本约束，界面不回填明文凭证 |

条件结构、字段名、分支 ID、输出 Schema、操作枚举、工具白名单、代码执行权限、运行预算和拓扑配置只能静态配置。条件中的比较值、HTTP 地址和正文、SQL 参数、文件路径、提示词等数据可绑定。资源选择在运行开始前解析并冻结；需要跨环境部署时使用项目资源别名。

变量选择器只展示当前激活路径可获得的上游结果、入口输入和作用域变量。循环体可见 `item`、`index`、累积状态；并行分支互不可见。可选分支结果必须先通过归并节点，或通过显式的存在性判断处理。引用缺失时默认报错，需要默认值时由用户指定，不能把字段缺失自动变成空字符串。

表达式与字段映射共用路径、条件和纯函数定义。内置函数族包含文本、数字、日期、对象和列表操作；当前时间作为运行开始时冻结的上下文值提供。表达式只能在本次输入内求值，运行成本受限。

| 编辑器 | 用途 |

| 资源选择器 | 项目默认、已连接资源、可用状态、能力说明；新建连接进入资源设置，保留节点草稿 |
| 路径选择器 | 对象字段、数组索引和受限路径查询；显示样本和匹配类型，区分单值与多值结果 |

| 表格映射器 | 列、类型、表头与样例；适用于 CSV、Excel、SQL 和批量数据 |

## 数据和执行契约

### 类型和结果

基础类型为 string、number、integer、boolean、null、object、array。扩展类型为 FileRef、Document、Table、ArtifactRef、Message、Vector；扩展类型有可序列化结构和版本，不能仅靠显示名称判断。

| 扩展类型 | 最小字段和行为 |
| --- | --- |
| FileRef | 文件 ID、名称、媒体类型、大小、内容校验值；后端解析位置和访问权，工作流不携带私有绝对路径或明文存储凭证 |
| Document | 文本或内容块、源文件引用、页码或段落位置、元数据；抽取和 OCR 可保留来源 |
| Table | 列 Schema、行数据或分页数据引用、行数；大表用引用传递，结果面板按页读取 |
| ArtifactRef | 产物 ID、名称、媒体类型、文件或内容引用、生成执行 ID |
| Message | 角色、文本或多模态内容块、附件引用；工具调用记录由运行时关联 |
| Vector | 向量值或批量引用、维度、模型标识、归一化状态；与索引维度不匹配时拒绝写入 |

字段缺失与显式 null 分别处理。所有节点输出明确的字段对象，动态字段要求提供 Schema 或标记为未知类型；未知类型可以通过校验或转换节点收窄。

**一次节点激活产生一个结果对象。列表在字段内传递，不因数组长度隐式触发下游多次。** 需要多次执行时显式使用遍历节点；映射、分批和展开列表都属于数据转换。这样同一能力作为 Agent 工具时也保持一致的输入输出。

执行状态、耗时、次数、费用和来源执行 ID 存在运行元数据中，不占用业务结果的同名字段。下文中的 `result`、`items` 等均指节点输出的直接字段。错误端口使用统一的 `error` 对象，包含错误类型、说明、字段位置、可重试性和脱敏后的来源信息。

### 公共配置

| 字段 | 默认值 | 规则 |
| --- | --- | --- |
| 名称、说明 | 类型名称、空 | 名称 1–80 字，说明可选；名称变化不影响引用 |
| 输入绑定 | 按字段 | 发布时检查类型和作用域，运行时校验解析后的实际值 |
| 超时 | 继承 | 普通动作项目默认 60 秒，模型和浏览器默认 120 秒，代码默认 30 秒；均受后端资源上限约束 |
| 重试 | 1 次总尝试 | 可设 1–5 次；启用后默认首次间隔 1 秒、指数退避、间隔上限 30 秒并加抖动 |
| 错误处理 | 使所属作用域失败 | 可选错误端口、符合输出 Schema 的回退值；错误不伪装成正常空结果 |
| 测试样本 | 无 | 独立保存样本和配置版本；预览中的值不参与真实运行 |
| 结果保留 | 继承项目设置 | 凭证始终不进入结果；大文件、大表和完整工具日志通过引用读取 |

重试必须满足动作的幂等声明。纯转换和可安全重复的读取可以启用自动重试；有副作用的动作要求幂等键、连接能力或明确的重复执行策略。远端调用是否成功未知时记录为待核实，后端不能直接推定未执行。

参数解析错误、权限不足、Schema 不匹配和取消默认不重试。模型生成不默认整节点重试；结构化输出修正有单独次数配置，并计入预算。运行总期限覆盖节点及其子执行；等待类节点使用等待截止时间，不套用普通动作的 60 秒超时。

触发器、控制容器和终止节点只显示适用的运行设置，不机械提供所有重试选项。支持等待的节点保存检查点后释放执行资源；恢复关联原执行，继续使用冻结的工作流版本。

### 字段表约定

下文 `*` 表示必填；`=值` 表示默认值。可选项未注明默认值时为“不设置”，由资源或项目配置决定；资源没有有效默认值时要求选择。所有数值限制都在字段旁显示单位，项目或后端上限同时适用。节点 ID 是目标目录中的标识，不承担旧测试数据兼容要求。

## 触发节点

触发节点定义一次运行的入口；一个工作流可以配置多个触发器，但每次运行只有一个入口激活。共享业务输入定义在工作流输入 Schema，触发器负责将事件映射为该输入；其他入口在本次运行中视为未激活，不参与汇合等待。

| 节点和 ID | 必填配置 | 可选配置与默认值 | 输出和校验 |
| --- | --- | --- | --- |
| 手动触发 `trigger.manual` | 输入字段定义* | 表单标题、说明、字段默认值、测试样本 | `input` 符合工作流输入 Schema，`context` 含运行标识；支持从 API 提交同一输入 |
| 对话触发 `trigger.chat` | 消息到工作流输入的映射* | 附件类型、最大附件数=10、历史范围=当前消息，可选最近 N 条 | `input`、`message`、`attachments`、`sessionId`；历史条数受预算限制，不自动包含其他任务 |
| 定时触发 `trigger.schedule` | 频率或 Cron 表达式*、输入映射* | 时区=项目时区、起止时间、重叠策略=跳过、漏触发策略=跳过；可选有界排队或补触发 | `input`、`scheduledAt`、`triggeredAt`；预览最近 5 次触发，标明后台服务需运行；限制补触发数量和队列长度 |
| Webhook 触发 `trigger.webhook` | 路径标识*、请求方法*、输入映射* | 鉴权=生成令牌，可选 HMAC/连接策略；请求 Schema；响应模式=立即返回 202，可选等待结果，等待上限=30 秒 | `input`、脱敏 `request`、`requestId`；同步响应由返回结果节点完成；异步响应只返回运行引用；事件去重键可配置 |
| 文件变化触发 `trigger.file-change` | 文件资源*、目录*、事件类型* | Glob、递归=false、防抖=500ms、写入稳定等待=2 秒、输入映射 | `input`、`file`、`eventType`、`eventId`；监控目录受资源授权，节点自身输出可排除，事件 ID 用于去重 |
| 外部事件触发 `trigger.event` | 事件连接*、订阅类型*、输入映射* | 过滤条件、去重字段、事件 Schema、重叠策略=并发 | `input`、`event`、`eventId`；事件连接必须声明订阅、重连和重放能力，并发受项目上限约束 |

## 流程控制与人工交互

| 节点和 ID | 必填配置 | 可选配置与默认值 | 输出和校验 |
| --- | --- | --- | --- |
| 条件分支 `control.if` | 条件组* | 无 | `matched`；固定 `true/false` 两个互斥端口；条件值按类型比较，无隐式字符串转数字 |
| 多路选择 `control.switch` | 规则列表*，每条含稳定分支 ID、名称、条件 | 匹配方式=首个命中、默认分支=启用；可选全部命中，选择后汇合节点必填 | `matchedBranchIds`；首个命中为互斥分支；全部命中形成并行作用域，必须连接对应汇合；分支重排不改变引用 |
| 遍历列表 `control.foreach` | 数组*、子流程*、结果映射* | 执行方式=串行、并发数=4、错误行为=终止、结果顺序=输入顺序；错误可选保留错误记录或跳过 | `results`、`errors`、`processedCount`；循环体提供 `item/index`；并发选项仅在并行模式显示；空数组输出空结果 |
| 条件循环 `control.repeat` | 初始状态 Schema 与值*、子流程*、状态更新映射*、退出条件* | 条件检查=执行前、最大次数=20，可选执行后检查；达到上限=错误 | `state`、`iterations`、`exitReason`；状态跨轮保留，循环体可见轮次；上限范围 1–1000，并受运行预算约束 |
| 并行执行 `control.parallel` | 至少 2 个分支*、对应汇合节点* | 并发上限=项目默认 | 向分支传递同一输入和独立分支上下文；稳定分支 ID；分支到对应汇合形成封闭作用域，禁止跨分支变量引用 |
| 并行汇合 `control.join` | 所属并行作用域* | 完成条件=全部完成，可选首个成功或成功数达标；错误行为=立即失败，可选收集；达标后取消剩余=true | `results` 按分支 ID 保存结果或错误、`completedBranchIds`；达标数条件才显示目标数；只等待本次激活的分支，未启动分支不算失败 |
| 分支归并 `control.merge-branches` | 互斥来源*、输出 Schema*、各分支结果映射* | 无 | 映射后的字段对象；只接受可证明互斥的路径，执行一次；不承担并行同步，必填字段需覆盖所有可达分支 |
| 子工作流 `control.subworkflow` | 工作流资源*、版本*、输入映射* | 输出映射、调用期限=继承 | 按所选版本输出 Schema 展示字段；发布时固定版本，测试可选草稿；禁止无界递归，调用图和深度由后端校验 |
| 异常处理 `control.try-catch` | 执行子流程*、正常结果映射* | 捕获错误类型=全部可捕获错误、恢复子流程、恢复结果映射、最终清理子流程 | 统一结果字段、`recovered`；恢复结果必须符合正常输出 Schema；取消默认向外传播，清理在单独有界期限内尽力执行，清理失败保留主错误 |
| 流程控制 `control.stop` | 动作*=中止运行 | 中止状态=取消、原因；动作可选跳出循环或继续下一轮 | 中止时形成终止状态；跳出和继续只在最近循环作用域有效，停止该轮剩余节点；跳出时返回已完成结果和当前循环状态 |
| 延时等待 `control.delay` | 时长或目标时间* | 时区=项目时区 | `scheduledAt`、`resumedAt`；二选一，时长非负；持久化调度，重启后按原目标时间恢复 |
| 等待事件 `control.wait-event` | 事件连接*、事件类型*、关联键*、匹配条件*、等待期限* | 输出事件 Schema、超时端口=启用 | `event`、`receivedAt`；进入节点先登记持久化订阅再等待；用可靠事件源的游标或收件箱处理登记竞态；去重且只恢复一次 |
| 请求输入 `interaction.input` | 提示内容*、表单字段*、等待期限* | 接收位置=当前任务、提交按钮文字=继续、超时端口=启用；字段默认值 | `values`、`submittedBy`、`submittedAt`；复用字段 Schema；运行进入等待状态，回复关联该请求；普通对话消息不自动当作表单提交 |
| 人工审批 `interaction.approval` | 审批内容*、动作列表*、等待期限* | 接收位置=当前任务、意见=可选、材料附件、超时端口=启用 | `decision`、`comment`、`decidedBy`、`decidedAt`；动作有稳定 ID 并对应端口；审批决定绑定请求和运行版本，重复提交返回原结果 |

并行汇合的“首个成功”在所有分支均失败时失败；“成功数达标”在剩余分支全部成功也无法达标时失败。收集模式下全部完成可返回错误记录，首个成功和成功数达标仍须满足成功条件。取消剩余分支是尽力操作，已经发生的外部副作用不会撤销；结果保留各分支最终已知状态。

人工审批与动作授权相互独立。审批节点表达流程里的业务决定；动作执行时仍遵守项目授权。内置 Agent、手动 UI 和外部 MCP 不能通过增加审批节点扩大既有权限。

## 对象与结构化数据

| 节点和 ID | 必填配置 | 可选配置与默认值 | 输出和校验 |
| --- | --- | --- | --- |
| 字段映射 `data.map-fields` | 映射表*：目标路径、类型、取值 | 保留原字段=false；保留时需源对象；每字段默认值 | `result`；推导输出 Schema；目标路径冲突报错，不能同时覆盖对象及其子字段 |

| 分类路由 `ai.classify` | 模型资源*、输入*、分类列表* | 模式=单标签路由，可选多标签结果；兜底类别=其他、示例、说明 | `label` 或 `labels`、`explanation`；单标签每类固定端口；多标签只输出列表，需要显式遍历或分支；类别有稳定 ID；不默认提供未经校准的置信度 |
| Agent 执行 `ai.agent` | 模型资源*、目标或输入消息*、工具集* | 系统说明、上下文范围=本节点输入、最大模型轮次=20、最大工具调用=40、并发工具数=4、总时限=5 分钟、费用上限、输出=文本或 Schema、进度消息=自动 | `text` 或 `object`、`artifacts`、`stopReason`；工具含内置能力/MCP/固定版本子工作流；参数可预绑定；工具权限继承项目且只能收窄；触及预算按错误策略处理，已完成副作用仍留在轨迹 |

Agent 的工具选择器逐项展示读写性质和所需资源。允许绑定连接、工作目录等固定参数，只把需要模型决定的字段暴露给模型；调用时仍进行完整校验。工具集中允许空集合，此时明确显示为无工具的 Agent；空集合不获得默认全部工具。

Agent 的进度消息提供“自动、仅最终结果、关键进展”。自动模式允许模型在有意义的阶段变化时说明进展，不要求每次工具调用配一条文字。工具开始、参数、运行状态和结果由结构化事件展示。节点保留内部 Turn 与 Tool Call 的父子关系，展开节点结果可回看，画布上显示简短状态。

对话历史、工具调用结果和外部文件默认不作为跨次运行的隐式记忆。需要历史时显式映射消息，需要长期存储时显式选择存储或检索能力。模型资源、工具契约和工作流版本在运行开始冻结；运行中补充输入只影响获准继续的同一 Agent 执行，不修改已提交的节点定义。

## 代码与结果

| 节点和 ID | 必填配置 | 可选配置与默认值 | 输出和校验 |
| --- | --- | --- | --- |
| 执行代码 `execution.code` | 隔离执行器资源*、语言*、代码*、输入映射*、输出 Schema* | 依赖=执行器允许的固定版本、超时=30 秒、内存=256MB、网络=关闭、文件访问=仅映射文件、环境变量资源 | `result`，stdout/stderr 存于运行日志；只显示执行器支持的语言；Rust 后端调度独立执行器，脚本不能访问后端进程或数据库内部；内存与超时受资源上限限制 |
| 返回结果 `output.return` | 输出字段映射* | HTTP 状态=200、响应头；响应相关项仅在同步 Webhook 上下文出现 | 工作流结果符合声明 Schema；结束对应工作流调用作用域；一个可达完成路径只允许一个返回；循环体和并行分支不能直接终止外层返回 |
| 发送消息 `output.message` | 目标任务或消息连接*、内容* | 格式=Markdown、附件、回复目标、消息策略=新建，可选按消息键更新；流式=false | `messageId`、`deliveryStatus`；外部发送权限来自连接；更新时消息键必填；流式更新保持消息身份、按序提交；失败保留已知投递状态，不默认重复发送 |

工作流必须声明输出 Schema。分支在完成路径归并后返回，返回节点激活时要求所属作用域其他已启动分支已完成或被明确取消；不允许用“先到先返回”掩盖仍在执行的分支。调用方同步等待或异步查询，是调用入口的行为，不改变子工作流输出契约。

同步 Webhook 等待到期仍未完成时返回 202 和运行引用，工作流继续执行，最终结果通过运行查询获取。HTTP 连接只能响应一次；在异步响应之后，返回结果节点只保存工作流结果，不再次修改 HTTP 响应。

| 结构化字段 | 名称、类型、描述、必填、可空、枚举、嵌套字段；无法用目标模型严格格式表达的 Schema 在发布前指出 |

| 分类项 | 稳定 ID、标签、判定说明、样本；兜底类别有固定 ID，可重命名；单标签分类必须具备兜底路径 |
| Agent 工具项 | 能力 ID、资源绑定、展示说明、暴露参数、预绑定参数、允许的读写范围；预绑定与暴露字段不重叠 |
| 子工作流工具 | 固定版本、工具名、说明、输入参数映射、输出字段；发布时检查调用环，运行时共享总预算和深度限制 |
| Agent 输出 | 文本或结构化对象二选一；结构化时 Schema 必填；达到输出上限导致对象不完整时按失败处理 |
| Agent 等待 | 工具声明需要输入或授权时保存调用状态并等待，继承父运行期限；停止后将未完成调用标记取消或结果待核实 |
| 费用预算 | 仅在资源提供可核算价格时显示金额上限和币种；价格不可用时使用轮次、调用数、Token 和时间限制，不展示虚假精确金额 |

## 典型配置面板

以下是配置内容顺序，不引入新的窗口或模态流程。长内容可从对应字段展开到工作区编辑页。

| 面板 | 默认可见字段 | 默认收起的配置 | 输出预览 |
| --- | --- | --- | --- |
| 过滤列表 | 列表来源；AND/OR 条件组；样本匹配预览 | 运行设置 | items、匹配数、移除数；前 10 行样本 |
| HTTP 请求 | 方法与 URL；连接；Query；正文类型与内容 | 请求头、分页、响应解析、运行设置 | 状态、响应字段或文件；分页时显示 items |
| MCP 工具 | 连接；工具搜索；工具说明；必填参数；输出类型 | 可选参数、版本与运行设置 | 结构化字段、文本和文件内容块 |
| 信息提取 | 模型；输入文档；字段定义表 | 提取示例、来源证据、模型参数、运行设置 | data 字段树、缺失项；开启证据时可定位原文 |
| Agent 执行 | 模型；目标；已选工具；输出要求 | 系统说明、上下文、预算、进度消息、运行设置 | 最终结果、产物；过程以轮次与工具调用展开 |
| 人工输入 | 提示内容；表单字段；等待期限 | 展示位置、超时分支 | 可直接预览表单，测试使用独立请求而非回复真实运行 |
| 并行汇合 | 所属分支组；完成条件；各分支结果字段 | 错误行为、取消剩余、期限 | 按分支展示结果与状态，不用单个 result 覆盖多个分支 |

## 资源配置与工具暴露

资源在完整设置页或项目资源页管理，节点内只选择和绑定。资源类型包括模型、文件目录、网络连接、MCP、事件源、数据库、KV、对象存储、知识索引、浏览器、代码执行器和消息连接。每种资源声明能力、权限、连接状态和限制；工作流发布时检查所需能力，运行开始时解析为冻结引用。资源不可用时显示具体原因，保持节点配置可编辑。

| 目录类型 | 暴露方式 |
| --- | --- |
| 数据转换与执行动作 | 可按能力声明暴露为 Agent/MCP 工具，共用输入输出、错误、资源和副作用契约 |
| 触发器 | 作为订阅或入口管理能力，不能当成“执行一次并获得事件”的普通动作 |
| 控制容器、分支、汇合 | 由 Workflow Runtime 调度；不自动注册为模型工具 |
| 等待与人工交互 | 声明持久化和恢复能力，工具调用方必须支持异步结果与关联恢复；不支持的客户端可调用封装工作流并查询状态 |
| 完整工作流 | 发布固定版本后，可将输入输出包装成一个工具；保留内部节点轨迹和授权边界 |
| 工作流管理 | 创建、修改、校验、运行、查询和控制工作流，使用独立的管理工具命名空间 |

工具调用上下文绑定项目、任务、身份、资源权限、预期版本和取消信号。远程工具的描述仅用于发现和配置，不能提升执行权限。工具不支持取消、幂等或 Schema 输出时如实声明，界面和运行时不补造这些保证。

## 校验与可审阅结果

保存草稿允许未完成配置，发布和运行进行完整校验。前端提供即时提示，Rust 后端负责权威检查。校验结果必须定位到节点、字段、端口或作用域，并包含可操作的说明。

| 时机 | 检查内容 |
| --- | --- |
| 字段编辑 | 类型、必填、枚举、范围、表达式语法、Schema、重复字段 |
| 图编辑 | 引用可达性、循环作用域、分支和汇合配对、返回路径、跨分支引用 |
| 发布 | 全部可达配置、资源能力、工具与子工作流契约、输入输出类型、无界递归、运行预算 |
| 运行开始 | 资源可用性和授权、冻结版本、实际入口输入、依赖快照 |
| 节点执行前 | 参数解析后的实际值、输入 Schema、路径和操作权限、剩余预算 |
| 恢复与重试 | 原请求和执行身份、幂等状态、等待期限、外部动作已知结果 |

单节点测试默认使用手工样本或选定历史运行的输入快照，不自动执行全部上游。需要真实上游数据时显式选择“运行到此处”，展示将执行的节点范围和副作用。真实测试使用真实资源权限，无法模拟为已成功；模型和工具调用显示实际消耗。

结果区统一显示输入解析值、业务输出、执行状态和诊断。对象用字段树，列表用表格，文件用预览或下载，文档可定位页码，AI 和工具执行可展开过程。测试完成后修改配置，旧结果仍可查看但标记为“来自旧配置”，不作为当前输出已验证的证据。

每个节点目录项除执行 Schema 外，还声明名称、分类、搜索别名、字段布局、条件显示规则、默认值、可绑定性、输出推导、图约束、资源要求和工具暴露能力。画布配置面板、节点搜索、Agent 发现和 MCP 描述由同一份注册定义提供，避免只返回类型名称、再由不同入口分别猜测参数。

## 当前控制流实现范围

Rust 已实现 `control.switch`、`control.parallel`、`control.join`、`control.merge-branches`、`control.repeat`、`control.break`、`control.continue`；`loop` 支持串行和有界并发遍历。控制契约集中在 `server/catalog/control-nodes.json`，API、MCP 和节点配置共同读取。现有 `condition` 保留固定通过/否则的简单路由。

结构化分叉与汇合双向关联，端口采用稳定分支 ID；互斥归并和并行汇合采用不同执行规则。并行汇合支持全部完成、首个成功和成功数达标，提前达标后取消剩余分支；取消不撤销外部动作。循环、分叉和子图可嵌套，后端禁止跨分支引用与非法控制信号；父执行、作用域、分支路径和轮次进入事件记录。画布使用显式静态端口及坐标，禁止 dynamic port。

遍历保留输入顺序；失败可终止、保留空位或移除失败结果。break/continue 只用于最近的串行循环，并行遍历和穿过并行分支的控制信号被拒绝。条件循环支持前置或后置退出判断、状态 Schema、显式状态更新和次数限制。图定义随完整运行冻结；恢复检查点、通用重试与异常容器、持久化等待及固定发布版本子工作流仍属于目标能力。
